# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/); dates use Asia/Dubai.

## [1.0.0] — 2026-11-08
### Added
- First public release of the interactive, bilingual human-anatomy explorer.
- Body-systems explorer: pan/zoom, front & back views, labelled structures.
- Disease encyclopedia, drug reference, reference lab cards, first-aid guides,
  and a sectioned library.
- English / Arabic (RTL) with light / dark themes.
- Pure static build — vanilla HTML/CSS/JS, no backend, no tracking.
